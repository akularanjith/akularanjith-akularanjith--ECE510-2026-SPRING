# Milestone 4 Deliverables

This directory contains the final synthesis, RTL source code, testbenches, and benchmarking results for the ILS accelerator.

| File Path | Description | Supports |
| :--- | :--- | :--- |
| `report/design_justification.pdf` | Final design report | Step 5 Deliverable |
| `report/figures/` | Referenced images/diagrams | Figure Requirements |
| `rtl/localization_core.sv` | Top-level hardware accelerator | Architecture Section |
| `rtl/cnn_mac_wrapper.sv` | MAC array and dataflow logic | Architecture Section |
| `tb/tb_localization.v` | SystemVerilog testbench | Verification Section |
| `bench/benchmark.md` | Throughput and energy data | Section 8 (Benchmark) |
| `bench/benchmark_data.csv` | Raw measurement data | Section 8 (Benchmark) |
| `bench/roofline_final.png` | Final roofline plot | Section 2 (Roofline) |
| `synth/area_report.txt` | Synthesis area results | Section 7 (Synthesis) |
| `synth/power_report.txt` | Power estimation results | Section 7 (Synthesis) |
| `synth/timing_report.txt` | Timing/Slack reports | Section 7 (Synthesis) |

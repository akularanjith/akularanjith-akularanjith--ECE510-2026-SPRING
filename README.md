# Indoor Localization System Accelerator (ECE 410/510)

This project implements a hardware-accelerated Convolutional Neural Network (CNN) engine for an indoor localization system (ILS) using RSSI data. This repository contains the complete design flow from software baseline modeling in Milestone 1 through physical synthesis in Milestone 4.
